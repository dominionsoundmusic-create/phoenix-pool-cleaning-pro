# Fact-check fc5 (Oct 9 2026)

Independent checker fc5. I did not write these pages. Searches used: 34 of 34. Evidence is WebSearch result summaries of the official or named source pages. Validation: `build.py --out /tmp/fc5/dist` built; `check.py --skip-links --only` gave 0 errors and 0 warnings on all six pages; `similarity.py` against Houston gave max Jaccard 0.1 to 0.2% and 0 shared 8-word runs per page (no FAIL). The largest Phoenix pair among these pages is 2.5%.

Brand rule: the Hayward and Pentair names were taken out of all visible body copy and FAQs. The 8 to 10 psi rule is now credited to neutral sources (Angi's filter guide, Pool and Spa News "The Pressure's On"). One Hayward knowledge-base page is still listed as a source on two filter pages, for the pump and filter sizing claim only, because no neutral source for it came up. All Pentair sources were removed.

"Not searched" means I ran out of search budget. Those items were kept only when they are well-established guidance from the named agency and are flagged here for a cross-check.
